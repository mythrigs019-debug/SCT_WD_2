# ⏱️ ChronoTrack — Stopwatch Web Application

A modern and responsive stopwatch web application developed as part of the **SkillCraft Technology Web Development Internship — Task 02**.

## 🚀 Project Overview

ChronoTrack is an interactive stopwatch application designed to accurately measure and record time intervals.

The application provides essential stopwatch controls along with lap-time tracking in a clean and responsive interface.

## ✨ Features

- ▶️ Start the stopwatch
- ⏸️ Pause the stopwatch
- 🔄 Reset the stopwatch
- 🏁 Record lap times
- 📋 Display multiple lap records
- ⏱️ Accurate time measurement
- 📱 Responsive design
- 🎨 Modern user-friendly interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
